# 예지보전 판정 정책

## 운영 판정 순서

1. 장비별 정상 구간의 3시간 이동평균으로 센서 한계를 계산한다.
2. 핵심 센서 8개 중 5개 이상이 한계를 벗어나면 전조 후보로 본다.
3. 5개 이상 이상 상태가 6시간 지속되면 공식 `고장 예상`으로 확정한다.
4. L2 정규화 로지스틱 회귀가 현재 고장 양성이고 이상 센서가 7개 이상이면 `실제 고장`으로 확정한다.
5. Random Forest는 전조가 실제 고장으로 진행될 가능성을 보조점수로 제공한다.

## 센서 규칙과 보조 모델의 관계

| 센서 6시간 규칙 | Random Forest | 화면 및 운영 판정 |
| --- | --- | --- |
| 충족 | 동의 | 고장 예상 · 높은 신뢰 |
| 충족 | 이견 | 고장 예상 유지 · 모델 이견 표시 |
| 미충족 | 위험 | 집중 관찰 · 공식 고장 예상 전 단계 |
| 미충족 | 정상 | 정상 관찰 |

현재 데이터에서는 Random Forest를 필수 조건으로 사용하면 실제 고장 1건을 놓쳤다.
따라서 모델은 센서 규칙으로 발생한 경보를 취소할 수 없다.

## 데이터/API 필드

- `current_fault_probability`: L2 현재 고장 확인 확률
- `progression_probability`: Random Forest 전조 진행 보조점수
- `progression_model`: 보조 모델 이름 또는 버전
- `operational_state`: 센서 지속 규칙과 현재 고장 확인 결과로 정한 공식 상태

기존 CSV에는 보조 모델 열이 없어도 정상 적재된다. 이때 화면에는 `보조 모델 미연결`로
표시하며 공식 판정은 센서 규칙만 사용한다.
